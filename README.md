## 🔒 How I Approach DevSecOps

- **Automate infrastructure:** version-controlled, repeatable and reviewable cloud configuration.
- **Build quality gates:** tfsec, TFLint, Checkov, SonarQube, TruffleHog and Super Linter in pipelines.
- **Protect credentials:** Azure Key Vault and Managed Identity instead of hard-coded secrets.
- **Apply least privilege:** RBAC reviews and controlled network exposure before deployment.
- **Govern at scale:** Azure Policy and policy-as-code across subscriptions.
- **Make changes safely:** inspect Terraform plans, enforce branch policies and mandatory PR reviews.
- **Control cost:** right-sizing, auto-shutdown, idle resource clean-up and reserved capacity.
