## 🧠 How I Think About DevOps & DevSecOps

- ⚙️ **Automate everything repeatable:** infrastructure, patching and operational workflows as code.
- 🧱 **Standardise:** reusable Terraform modules and pipeline templates so every team starts from a good baseline.
- 🔍 **Shift left:** tfsec, TFLint, Checkov, SonarQube and TruffleHog run in the pipeline, before deployment.
- 🔄 **Release safely:** reviewed plans, branch policies, mandatory PR reviews and rollback stages.
- 📊 **Keep it reliable:** monitoring and alerting with Azure Monitor, Log Analytics, Prometheus and Grafana.
- 💸 **Control cost:** right-size, auto-shutdown, remove idle resources and review reserved capacity.
